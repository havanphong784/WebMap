# Aether Android App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Package the existing Aether React/Vite product as a production-ready Android app with reliable native authentication, location, system integration, and a repeatable signed-AAB build.

**Architecture:** Capacitor hosts the existing Vite bundle in an Android shell. Platform differences are isolated behind focused adapters in `frontend/src/platform`, while Firebase Web Auth remains the canonical session used by the existing API client. The backend gains an explicit Capacitor-origin policy and release configuration is validated before any production bundle is built.

**Tech Stack:** React 19, Vite 8, Vitest, Capacitor 8 Android, Capacitor Firebase Authentication 8, Firebase Web SDK, Express 5, Node 22+, Gradle, Android SDK 36

**Spec:** `docs/superpowers/specs/2026-10-16-aether-android-design.md`

## Global Constraints

- Android application id is `com.aether.geo`; display name is `Aether Geo`.
- Capacitor core, Android, official plugins, and Capacitor Firebase Authentication use compatible 8.x releases recorded exactly in `package-lock.json`.
- Build host uses Node.js 22+ and Android Studio 2025.2.1+; minimum SDK is 26 and compile/target SDK is 36.
- Release API traffic is HTTPS only and may not point to localhost.
- Components must use `frontend/src/platform` adapters rather than importing Capacitor plugins directly.
- Firebase Web Auth remains the canonical source of the ID token consumed by `apiClient` and SSE.
- Do not commit `google-services.json`, keystores, signing properties, `.env.android`, or `.env.android.local`.
- No background location, push notification, offline map, iOS, or native UI rewrite is in scope.

## Review Focus

- Location permission denied or permanently denied: show a recoverable state and never crash or loop permission prompts; pinned in Task 3 adapter tests.
- Google native sign-in cancelled or missing an ID token: leave the existing session untouched and surface a Vietnamese error; pinned in Task 4 auth tests.
- Release API URL is absent, cleartext, or localhost: stop the build before Vite or Gradle packages it; pinned in Task 1 config tests.
- Android Back while an overlay is open or while on a root tab: close the overlay first and require double-back before exit; pinned in Task 2 navigation tests.
- Capacitor origin is omitted from production configuration: reject it predictably and document the deployment value; pinned in Task 6 CORS tests.
